# sgBACES_2022
you will need to download fastica from this link "https://research.ics.aalto.fi/ica/fastica/code/dlcode.shtml" to run sICA, 
and spams toolbox "http://thoth.inrialpes.fr/people/mairal/spams/downloads.html" to run CODL and ShSSDL,
execute script_sim to run the simulation, 
this simulation is based on mat files for rgBACESW and sgBACES whereas the results reported in the paper are based on mex files, 
this is why you will find some difference in their run times

If you use this code in your paper please cite
M. U. Khalid, "Sparse Group Bases for Multisubject fMRI Data," in IEEE Access, vol. 10, pp. 83379-83397, 2022, doi: 10.1109/ACCESS.2022.3194651.
